# multilingual-e5-small-ru-law

`intfloat/multilingual-e5-small` (118M параметров, 384 измерения), дообученная для поиска статей законов РФ по вопросам людей: на синтетических вопросах к статьям Трудового, Гражданского, Жилищного кодексов и КоАП, с дистилляцией знаний из `ai-forever/FRIDA` (823M). Всё обучение занимает 19 минут на одной RTX 3070.

**Результат:** на тесте [RuLawRetrieval](https://huggingface.co/datasets/alekseevpavel04/ru-law-retrieval) nDCG@10 растёт с 0.802 до **0.859** (+0.057, 95% ДИ [+0.042; +0.073]). Это уровень `multilingual-e5-large` (560M, 0.859; разница +0.001 [−0.016; +0.017], то есть модели статистически неотличимы) при задержке на CPU в 6.7 раза меньше и индексе в 2.7 раза меньше. На трудном наборе бытовых и поисковых вопросов по ТК прирост ещё больше: 0.710 → **0.820** (+0.109 [+0.091; +0.128]).

*English summary: `multilingual-e5-small` fine-tuned on synthetic Russian legal questions with knowledge distillation from FRIDA (823M). On the RuLawRetrieval test set nDCG@10 goes 0.802 -> 0.859, matching `multilingual-e5-large` (560M) while being 6.7x faster on CPU; on the harder TK set 0.710 -> 0.820. Training takes 19 minutes on one RTX 3070. The largest gains are on colloquial questions (0.569 -> 0.701).*

Код, данные и все эксперименты: [github.com/alekseevpavel04/ru-law-retrieval](https://github.com/alekseevpavel04/ru-law-retrieval).

## Использование

Префиксы обязательны, как у исходной e5: `query: ` для вопроса и `passage: ` для документа.

```python
from sentence_transformers import SentenceTransformer

model = SentenceTransformer("alekseevpavel04/multilingual-e5-small-ru-law")
query = ["query: меня уволили, пока я был на больничном, это законно?"]
passages = [
    "passage: Трудовой кодекс РФ, Статья 81. Расторжение трудового договора по инициативе работодателя\n"
    "Не допускается увольнение работника по инициативе работодателя (за исключением случая ликвидации организации "
    "либо прекращения деятельности индивидуальным предпринимателем) в период его временной нетрудоспособности "
    "и в период пребывания в отпуске.",
    "passage: Трудовой кодекс РФ, Статья 115. Продолжительность ежегодного основного оплачиваемого отпуска\n"
    "Ежегодный основной оплачиваемый отпуск предоставляется работникам продолжительностью 28 календарных дней.",
    "passage: Трудовой кодекс РФ, Статья 183. Гарантии работнику при временной нетрудоспособности\n"
    "При временной нетрудоспособности работодатель выплачивает работнику пособие по временной нетрудоспособности "
    "в соответствии с федеральными законами.",
]
q = model.encode(query, normalize_embeddings=True)
d = model.encode(passages, normalize_embeddings=True)
print(q @ d.T)  # ст. 81 уверенно первая; у исходной e5-small все три статьи почти не различаются
```

Абсолютные косинусы у дообученной модели ниже, чем у исходной e5: шкалу растягивает обучение с MultipleNegativesRankingLoss. Значение имеет порядок, а пороги отсечения (`min_score`) нужно подбирать заново.

Модель сохранена в классическом формате sentence-transformers: версии 3.3.1 и 6.1.0 дают на ней одинаковые эмбеддинги (проверено). Максимальная длина входа 512 токенов. Лучше всего работает, когда поиск идёт по фрагментам статей (500-600 символов) с заголовком статьи в начале каждого фрагмента, а score статьи равен максимуму по её фрагментам: так её обучали и оценивали.

## Как обучена

Двухэтапный рецепт, все решения приняты по dev (`results/v2_selection.json`):

1. **Контрастное обучение** (`CachedMultipleNegativesRankingLoss`, батч 128, мини-батч 32, 3 эпохи, lr 3e-5, bf16, таблица эмбеддингов словаря заморожена):
   - 16 тыс. синтетических вопросов (Qwen3-8B, два прохода с разными промптами) к 3.2 тыс. статей четырёх кодексов, три стиля: бытовой, поисковый, юридический;
   - позитивный фрагмент внутри своей статьи выбирает учитель FRIDA, он же майнит по одному hard negative (фрагменты эталонной статьи исключены, кандидаты со score ≥ 0.95 от позитива отброшены как вероятные ложные негативы);
   - вопросы, для которых учитель не находит свою статью в топ-50, отбрасываются как шум генерации (5%);
   - свой батч-сэмплер: в одном батче не бывает двух строк про одну статью.
2. **Дистилляция** (`DistillKLDivLoss`, 1 эпоха, lr 1e-5, батч 32): ученик повторяет ранжирование учителя FRIDA по 8 кандидатам на вопрос (позитив и 7 статей из его топа), температура учителя 0.02.

Обучение: 13 мин (этап 1) и 6 мин (этап 2) на RTX 3070 8 ГБ, пик памяти 2.9 ГБ.

## Ограничения

- Обучена на синтетических вопросах; на реальных вопросах качество может отличаться.
- Одна редакция законов (сентябрь 2026). На кодексах, которых не было в обучении (СК, ЗоЗПП), прирост меньше: +0.026 [−0.000; +0.052].
- Общий поиск проседает: RuBQ −0.027. Для смешанного сервиса стоит сравнить обе модели.
- Модель ищет статьи, а не даёт юридические консультации.
