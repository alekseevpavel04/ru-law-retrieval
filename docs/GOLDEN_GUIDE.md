# Инструкция по разметке golden-набора

Golden: подмножество тестовых вопросов, проверенное вручную. Для каждого вопроса есть эталонная статья (по ней LLM сгенерировала вопрос) и 5 кандидатов из пула поиска (BM25 + лучшая baseline-модель, без эталона).

## Что решить по каждому вопросу

1. **Вопрос** (`question_status`):
   - `ok`: вопрос понятный, на русском, по-человечески сформулирован, без утечек (номер статьи, «в данной статье»);
   - `fix`: смысл хороший, но формулировка кривая (опечатка, лишнее, невнятно). Исправленный текст пишется в `fixed_text`. Исправлять минимально, не подгонять под статью;
   - `drop`: вопрос бессмысленный, не про право, вопросов несколько сразу, или на него невозможно ответить по законам из корпуса.
2. **Эталон релевантен** (`gold_relevant`): да, если по эталонной статье можно ответить на вопрос по существу (полностью или основную часть). Нет, если статья только про смежную тему.
3. **Другие релевантные** (`extra_relevant`): отметить кандидатов, которые **тоже** отвечают на вопрос по существу (например, та же норма в другом кодексе, общая и специальная норма, статья с санкцией за нарушение нормы). Кандидат, который только упоминает тему, не отмечается.

## Принципы

- Судим по тексту статьи, а не по знаниям о праве вообще.
- Бытовые вопросы (`everyday`) формулируются без терминов, поэтому релевантность определяется по сути ситуации.
- Поисковые запросы (`search`) короткие и неоднозначные: релевантной считается статья, которую разумный пользователь с этим запросом хотел бы найти.
- Если сомневаетесь в кандидате, не отмечайте его (golden должен быть точным, а не полным).
