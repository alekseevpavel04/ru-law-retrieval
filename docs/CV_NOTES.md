# Строки для резюме

Каждое число взято из файлов в `results/` (в скобках указан источник).

- Собрал открытый бенчмарк поиска по законам РФ в формате MTEB: 3 786 статей шести кодексов, 10 тыс. синтетических вопросов от двух LLM разных семейств, три среза обобщения, подмножество с повторной разметкой. Выяснил, что автоматическая разметка «вопрос → одна статья» неполна для 21% вопросов (`results/corpus_stats.json`, `results/dataset_stats.json`, `results/golden_stats.json`).
- Дообучил multilingual-e5-small (118M) на синтетических вопросах за 3.9 мин на одной RTX 3070 (GradCache, свой сэмплер без ложных негативов, свой майнинг hard negatives). nDCG@10 на тесте вырос с 0.802 до 0.845 (+0.043, 95% ДИ [+0.028; +0.058]), что статистически неотличимо от multilingual-e5-large (560M) при задержке на CPU в 6.7 раза меньше (`results/bootstrap.csv`, `results/headline.json`, `results/speed.json`).
- Сравнил 12 эмбеддеров и BM25 с парным бутстрапом по срезам. Показал, где дообучение ломается: на новых кодексах прирост незначим (+0.021, ДИ [−0.007; +0.049]), на общем домене есть забывание (RuBQ 0.686 → 0.651). Весь выигрыш приходится на бытовые вопросы (0.569 → 0.687) (`results/bootstrap.csv`, `results/forgetting.json`, `results/figures/qtypes.csv`).
- Внедрил дообученную модель в свой RAG-сервис по Трудовому кодексу (tk-rf-rag) с переключением модели через конфиг и замером «было/стало».
